## What to build

Prefactor the Swift-side state architecture into the workspace/tab split the
web already has, so the multi-tab and persistence slices become easy changes.
No visible behavior change: the app still opens with a single document and
every existing interaction works exactly as before.

Mirror the web's ownership boundaries (`Workspace` / `TabState` /
`SharedState`), adapted to SwiftUI idioms:

- **Per-tab state** — everything scoped to one open document: the document
  object, its history, the viewport, the document's display name and identity,
  and the Timeline panel collapse flag (the web persists it per document).
- **Workspace-shared state** — everything every tab sees by reference: active
  tool, foreground/background colors, recent colors, pixel-perfect flag, and
  the transient input state (Shift held, Constrain latch, text-input focus,
  keyboard shortcut controller).
- A workspace-level object owns the tab collection (a single tab for now) and
  the shared state, and exposes the active tab — the shape `addTab` /
  `closeTab` / `setActiveTab` will extend in the follow-up slice.

The stroke engine, keyboard shortcut host, and views should reach document
state through the active tab rather than through a flat editor object. Where
views only need shared state, they should not depend on tab internals.

This is the "Swift-side state-architecture redesign" the RFC folded into the
phase; do it here, in isolation, while behavior is easy to verify unchanged.

## Acceptance criteria

- Per-document state (document, history, viewport, name, Timeline panel
  collapse) lives in a tab-scoped object; cross-document state (tool, colors,
  recent colors, pixel-perfect, input transients) lives at workspace scope.
- The app's behavior is unchanged: the full Apple test suite passes and
  existing docked-view snapshots are byte-identical (no re-recording).
- Unit tests cover the new ownership seams at least where existing
  `EditorState` tests move — no test coverage is lost in the move.
- No UniFFI surface changes; `apple/src/lib.rs` is untouched.
