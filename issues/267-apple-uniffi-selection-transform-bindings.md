## What to build

Expose the selection and transform surface the Phase 5 selection track needs
through the UniFFI crate. **Expand only** — existing bindings and every
consumer stay untouched (the pattern issues 256/263 established).

Scope is defined by what the selection and transform slices consume — no
speculative surface:

- **Marquee**: a record carrying the Marquee rectangle (x, y, width, height)
  across the boundary; document reads/writes for the current Marquee
  (present or absent); the region helpers the shell consumes instead of
  reimplementing core edge cases — drag-corner normalization (`from_drag`),
  point containment, and canvas clipping.
- **Region ops**: clear the Marquee region to transparent, lift the Marquee
  region's pixels as an RGBA buffer, and composite a buffer back at a
  destination region — the primitives the Floating Selection lifecycle is
  built from. Include the bounded flood fill (fill stops at given bounds)
  that Marquee clipping needs.
- **Floating preview read**: the patch-composite read (composite with one
  layer's pixels substituted) that the Metal render path uses to preview a
  Floating Selection without mutating the document.
- **Canvas Transform tier**: whole-document flip horizontal/vertical and
  rotate CW/CCW, per the CONTEXT.md tier definition (all Pixel Layers × all
  frames, rotate swaps W↔H, Marquee co-transformed + clipped, Reference
  Layer fixed).
- **Marquee Transform tier**: Marquee-region flip horizontal/vertical and
  rotate CW/CCW (active Pixel Layer's active-frame Cel only; no-op without
  a Marquee).

No new core logic — the core `Document` and `selection` modules already
implement everything; this is binding work plus regeneration. Document
History needs no changes: its whole-`Document` snapshots already carry the
Marquee.

## Acceptance criteria

- Swift binding tests (following the existing `DocumentBindingsTests`
  pattern) prove through the generated bindings:
  - Marquee set/read round-trips, including the absent state;
  - lift → clear → composite-back reproduces a move (pixels land at the
    destination, source is transparent);
  - bounded flood fill stops at the given bounds; a seed outside them
    changes nothing;
  - the patch-composite read previews substituted pixels without mutating
    the document;
  - each Canvas Transform op transforms every layer, rotate swaps
    dimensions, and an active Marquee comes through mapped and clipped;
  - each Marquee Transform op touches only the Marquee region of the
    active layer and no-ops without a Marquee;
  - a canvas transform round-trip (flip twice, rotate four times) restores
    the original document.
- `cargo test` passes; UniFFI regeneration produces Swift that compiles in
  the Xcode project.
- Existing bindings, shell code, and shell behavior are untouched.
