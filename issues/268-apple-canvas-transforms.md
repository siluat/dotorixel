## What to build

The Canvas Transform tier on the Apple shell: four buttons — Flip Canvas
Horizontal, Flip Canvas Vertical, Rotate Right, Rotate Left — grouped with
the Canvas Size controls in the right panel, matching the web's placement
and the canvas-scoped labels (issue 207's tier model).

- Each button transforms the whole artwork: every Pixel Layer (all frames
  once frames exist), rotate swaps the canvas width/height. The core ops
  from the 267 bindings do the work; the shell wires, renders, and records
  history.
- One button press is **one undoable step** through the existing Edit
  Baseline path: undo restores pixels and canvas dimensions together (the
  Document History snapshot already covers the Marquee when one exists).
- After a rotate, the viewport reclamps to the swapped dimensions the same
  way canvas resize does today.
- Labels are canvas-scoped ("Flip Canvas …") and localized in the String
  Catalog (en/ko/ja), mirroring the web's message keys.

Interplay notes: an active Marquee is co-transformed by the core — no shell
work needed beyond re-rendering any selection overlay once it exists. The
"commit a pending Floating Selection before a canvas transform" policy
belongs to the Floating Selection slice (272), which lands later and must
extend these buttons' dispatch path.

## Acceptance criteria

- The four buttons appear grouped with Canvas Size in the right panel with
  canvas-scoped labels in en/ko/ja.
- Flip mirrors every Pixel Layer together (multi-layer artwork stays
  aligned); rotate turns every layer and swaps W↔H, and the Metal view
  renders the new dimensions correctly.
- Each transform is a single undo entry; undo restores pixels + dimensions
  (+ Marquee, once the selection tool exists); redo re-applies.
- A transform on an unchanged document (not possible for flip/rotate — they
  always change a non-symmetric document) still routes through the Edit
  Baseline so a symmetric-image no-op pushes no history entry.
- Tests at the shell seam (following the existing `TabState` /
  view-snapshot patterns) cover dispatch, undo round-trip, and the
  viewport reclamp after rotate.
