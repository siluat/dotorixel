## What to build

Hardware-keyboard operations on the Marquee and Floating Selection,
matching the web:

- **Arrow nudge**: arrows translate by 1 px, Shift+arrow by 10 px. The
  first press auto-lifts the Marquee into a Floating Selection; subsequent
  presses stack into the same buffer. Nudges never push per-press undo
  entries — the accumulated translation commits as the Floating's single
  undo step.
- **Delete/Backspace**: with an idle Marquee, clears the region to
  transparent as one undoable step; with a Floating active, follows the
  web's policy for the same keys.
- **Escape**: with a Floating active, cancels it — lifted pixels return to
  their source, the pre-lift Marquee is restored, and no history entry is
  pushed. With only an idle Marquee, Escape deselects.
- **Shift axis lock**: holding Shift during a Floating drag locks
  translation to the dominant axis; toggling mid-drag re-resolves the
  preview immediately (the web's axis-lock behavior).
- All of it respects the existing text-field guard (keys typed into text
  inputs never reach the canvas) and is a silent no-op while a Reference
  Layer is active (future-proofing for the reference track).

## Acceptance criteria

- Arrow/Shift+arrow nudge by 1/10 px, auto-lifting on the first press;
  the whole nudged move is one undo entry on commit.
- Delete clears the Marquee region as one undoable step.
- Escape cancels a Floating (pixels restored, Marquee restored, no history
  entry) and deselects an idle Marquee.
- Shift during a Floating drag locks to the dominant axis, live.
- Keys in text inputs never trigger selection ops.
- Tests cover nudge accumulation + single-undo, delete undo round-trip,
  Escape's two behaviors, axis-lock resolution, and the text-field guard.

### Key Decisions

- Use a platform-neutral semantic key type so AppKit and UIKit key codes do not leak into shortcut policy.
- Keep keyboard nudges inside the transient Floating Selection; History records only the eventual commit.
- Let the Core Edit Baseline decide whether Delete changed pixels instead of predicting no-ops in the shell.
- Choose the dominant axis when Constrain activates and hold it until Constrain turns off, matching web behavior.
