## What to build

The Selection Clipboard (per the CONTEXT.md glossary: a workspace-shared
single slot — not the OS clipboard) with ⌘C / ⌘X / ⌘V:

- **Copy (⌘C)**: stores the Marquee region of the active Pixel Layer as
  `{ pixels, width, height }`. No document mutation, no history entry.
- **Cut (⌘X)**: copy + clear the region to transparent as one undoable
  step.
- **Paste (⌘V)**: materializes the clipboard as a Floating Selection
  centered on the visible-document area (viewport ∩ canvas intersection;
  canvas center when the intersection is empty). A pre-existing Floating
  commits first; a pre-existing Marquee is discarded (and restored by undo
  of the eventual commit). The pasted Floating behaves exactly like a
  lifted one — drag to reposition, Escape to cancel, same commit triggers,
  one undo entry on commit.
- The slot is workspace-scoped: copy in one tab, switch tabs, paste in
  another. Empty-clipboard paste and copy/cut without a Marquee are silent
  no-ops. All three shortcuts respect the text-field guard and no-op while
  a Reference Layer is active.
- Shortcuts ride the existing keyboard plumbing (and the macOS Edit menu
  where the app already surfaces undo/redo, if that falls out naturally —
  menu integration is not required for this slice).

## Acceptance criteria

- ⌘C then ⌘V pastes a pixel-exact copy centered in the visible canvas
  area; committing it is one undo entry whose undo restores pre-paste
  pixels and the pre-paste Marquee.
- ⌘X clears the source as one undoable step and the content pastes back.
- Copy in tab A pastes in tab B (workspace scope).
- Paste with an active Floating commits it first; paste with the canvas
  fully off-screen centers on the canvas.
- Empty clipboard / no Marquee cases are silent no-ops; text inputs are
  guarded.
- Tests cover the copy/cut/paste round-trip, paste positioning (both
  branches), commit-first behavior, cross-tab scope, and the no-op guards.

### Key Decisions

- Keep the clipboard app-local and workspace-scoped, never in the OS clipboard or Layer stack.
- Model Floating Selection provenance explicitly while retaining one lifecycle for lifted and pasted content.
- Keep visible-canvas coordinate math in the Apple shell behind a private viewport query because the simple shell geometry does not justify binding overhead.
- Make `SelectionClipboard` valid by construction so invalid pixel buffer dimensions cannot cross into the lifecycle.

### Notes

- The Selection Clipboard is session-transient and is not persisted across relaunches.
- Verified the full Apple test suite on the pinned iPad simulator and a macOS app build.
