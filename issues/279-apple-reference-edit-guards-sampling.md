## What to build

The behavioral contract around an active Reference Layer, matching the
web's single-authority model (CONTEXT.md: whether the active layer is
editable is decided in one place, enforced at the state boundary — tools
trust the precondition):

- **Paint no-op**: with the reference row active, every drawing tool
  (pencil, eraser, shapes, fill, move) is a silent no-op with a clear
  visual signal (the web shows a not-allowed cursor; use the platform
  equivalent — pointer cursor on macOS/iPad pointer, plus a disabled
  affordance where a cursor doesn't exist for touch). No history entries,
  no dirty marks.
- **Marquee no-op**: Selection-tool defines, Floating operations, Marquee
  Transforms, and clipboard ops no-op while the reference is active; the
  selection UI (overlay, action bar, readout) hides, but an existing
  Marquee is preserved and returns when a Pixel Layer becomes active
  again (web issue 205 behavior).
- **Mid-stroke seal**: the existing guards that keep a live stroke's
  target layer from switching or vanishing extend to the reference —
  activating the reference row mid-stroke cannot redirect paint.
- **Sampling reads the underlay**: the eyedropper and the sampling loupe
  switch from the Pixel-only composite to the what-you-see read (277's
  `try_get_pixel` semantics): over reference content not covered by pixel
  art they sample the reference color — the tracing workflow's core loop.
  Transparent and out-of-bounds samples keep their existing skip
  behavior; the loupe's neighborhood grid reads the same way so the
  magnified preview matches what commits.

## Acceptance criteria

- With the reference active: every paint tool leaves pixels, history, and
  dirty state untouched, and the UI signals non-editability; selection
  surfaces hide while a pre-existing Marquee survives the round-trip back
  to a Pixel Layer.
- Activating the reference mid-stroke does not redirect or corrupt the
  in-flight stroke.
- Eyedropper over visible reference content (no pixel art above) commits
  the reference color to FG/BG; over pixel art it samples the pixel art;
  with the reference hidden it samples as today. The loupe grid matches
  the committed sample in all three cases.
- Tests cover the editability authority (one predicate, consulted at the
  boundary), each tool's no-op, selection-UI hide/restore, the mid-stroke
  seal, and the three sampling cases.
