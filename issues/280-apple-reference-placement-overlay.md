## What to build

Positioning the reference for tracing: with the reference row active, a
placement overlay appears around the underlay's footprint and placement
becomes directly manipulable.

- **Overlay**: a bounding box drawn at the reference footprint (277's
  rotation-aware read), tracking zoom/pan. Visible only while the
  reference is active; the paint no-op from 279 is what frees the canvas
  gestures for placement.
- **Move**: dragging inside the box translates the placement, live.
- **Scale**: corner-handle drag scales about the placement anchor
  (web behavior); on touch, pinch scales as well. Holding Shift snaps to
  integer scale factors (web's snap); scale respects the core invariant
  (> 0) at the boundary.
- **Keyboard nudge**: arrows translate placement by 1 px, Shift+arrow by
  the web's multiplier — same keys the selection track uses, routed by
  which feature is active.
- **Fit to canvas**: a fit action (Timeline reference-row affordance, web
  parity) recomputes the auto-fit placement through the core.
- Each completed gesture (drag release, pinch end, fit, nudge burst)
  commits one undoable edit through the Edit Baseline — placement changes
  are document history like any edit, and mark the document dirty.
- Handles and the box meet ≥44 pt touch targets; the overlay never blocks
  the Timeline panel or toolbars.

## Acceptance criteria

- Activating the reference shows the overlay at the footprint; deactivating
  hides it.
- Drag moves the underlay live; corner drag and pinch scale it; Shift
  snaps scale to integers; arrows nudge (with Shift multiplier).
- Fit-to-canvas restores the auto-fit placement in one step.
- Every completed gesture is a single undo entry; undo walks placement
  states back one gesture at a time; a net-zero gesture pushes nothing.
- Placement edits re-render the underlay and mark the document dirty
  (auto-save picks them up once 282 persists placement).
- Tests cover the footprint↔screen projection, each gesture's placement
  math, the integer-scale snap, invariant enforcement at the boundary,
  fit, and the one-gesture-one-undo contract.
