## What to build

Grow the Timeline panel's placeholder frame area (reserved by 261 with
the M3 treatment, exactly as the web once did) into a real frame axis —
the web TimelinePanel's frame ruler as reference, SwiftUI-native
controls per the hybrid principle:

- **A column per frame** with a ruler header carrying the frame's
  1-based ordinal. The `[layer row × frame column]` cell shows an
  occupied/empty indicator (web-parity fidelity; full thumbnails stay
  out of scope, as on the web).
- **Tap a frame header to activate it**: the canvas switches to that
  frame's composite, and every drawing tool writes into the active
  layer's Cel for that frame (both arrive through the core — verify at
  the shell seam).
- **The active frame column is visually highlighted** (combined fill +
  accent, matching the active-layer treatment for color-blind safety).
- **Frame selection never enters undo history** — navigating the
  timeline doesn't pollute undo, mirroring layer activation.
- **Switching frames resolves an in-flight Floating Selection first**
  (commit before the switch), so lifted pixels land on the Cel they came
  from rather than leaking into another frame — the web's PRD 186
  contract, now applicable because the Apple shell has floating
  selections (272).
- Sidebar rows and frame columns stay scroll-aligned as they are today;
  the reserved transport-strip slot above the ruler remains a dim
  placeholder (289 fills it).

Until 285 lands the UI can only ever show one frame; multi-frame
behavior is exercised through tests that build documents via the 283
bindings.

## Acceptance criteria

- N frame columns render for an N-frame document, in axis order, with
  1-based ordinals.
- The active frame is highlighted; tapping another header activates it,
  the canvas shows that frame's composite, and drawing mutates only that
  frame.
- Activating a frame pushes no history entry; undo after a
  draw-switch-draw sequence restores the expected frame's pixels.
- Switching the active frame with a floating selection in flight commits
  it to its origin Cel first.
- Touch targets ≥ 44 pt; any new labels in the String Catalog
  (en/ko/ja); docked snapshot baselines updated.
