## What to build

The frame ruler's structural operations, making multi-frame authoring
reachable from the UI (web frame-operations parity, adapted to the
panel's existing icon-button idiom):

- **Add (＋)**: inserts a new empty frame directly after the active
  frame and activates it — every Pixel Layer gets a transparent Cel.
- **Duplicate**: inserts a copy of the active frame after it and
  activates the copy — every Pixel Layer's active-frame Cel is cloned,
  preserving the whole composited moment.
- **Remove**: deletes a frame. The affordance follows the web's
  convention for the last remaining frame (a document never has zero
  frames); removing the active frame activates an adjacent one.
- All three are **undoable** through the existing whole-document
  snapshot history (begin/end edit), restoring both frame structure and
  Cel pixels in a single undo.
- Reuse the shared panel icon-button helper (compact chrome, 44 pt hit
  area) the layer controls already use.

Drag reorder is a separate slice (286).

## Acceptance criteria

- Add yields a new active frame whose composite is fully transparent;
  the previous frame's pixels are untouched.
- Duplicate yields a new active frame whose composite equals the source
  frame's; editing the copy leaves the source unchanged.
- Remove on a multi-frame document deletes the frame and activates an
  adjacent one; the last remaining frame cannot be removed via the UI.
- Undo after each operation restores the prior frame structure and
  pixels; redo reapplies it.
- Touch targets ≥ 44 pt; new labels in the String Catalog (en/ko/ja);
  snapshot baselines updated.
