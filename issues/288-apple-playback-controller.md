## What to build

The playback engine for a tab — the web's transient-playhead
architecture (PRD 199), ported to Swift. Playback is a **preview, not an
edit**: it never mutates the document, never moves the Active Frame,
never marks the document dirty, and never enters undo history.

- **State (transient, never persisted)**: `isPlaying`, `isLooping`, and
  the current playhead frame. A tab always starts stopped.
- **Pure advance function** — the testability seam: `(playheadIndex,
  accumulatedMs, durations, isLooping) → (nextIndex, carryMs, stopped)`.
  Leftover time carries into the next frame so variable durations don't
  drift; at the sequence end it loops (Loop on) or stops (Loop off); a
  single-frame sequence never advances.
- **Clock wrapper**: a display-linked tick feeds real elapsed time into
  the advance function; the canvas re-composites only when the playhead
  frame actually changes, not every tick. The clock choice
  (CADisplayLink / TimelineView / timer) is an implementation decision.
- **Display-buffer override**: while playing, the buffer the Metal
  renderer draws is `composite_at(playhead)` — committed art only, no
  floating-selection overlay; while stopped it is the normal edit
  composite. The renderer itself is untouched — the override lives at
  the composite-buffer seam the tab state already owns.
- **Start resolves edit state**: starting playback first commits any
  in-flight Floating Selection. **Play starts from the first frame** for
  a predictable, repeatable preview.
- **Lifecycle**: pausing, Loop-off completion, switching tabs, closing a
  tab, or a structural document change stops playback and returns the
  canvas to the Active Frame; a backgrounded tab never keeps a clock
  running.

Transport controls arrive in 289; this slice is verified through its
tests (pure advance matrix + tab-state integration through the real
bindings).

## Acceptance criteria

- Pure-advance tests cover, with synthetic elapsed values: advancement
  at each frame's own duration, proportional holds, carry without drift,
  loop-on wrap, loop-off stop on the last frame, and the single-frame
  no-op.
- Integration tests through the real bindings prove: starting playback
  exposes the playhead composite through the display buffer while the
  Active Frame and document state are unchanged; stopping returns to the
  active-frame composite; starting commits an in-flight floating
  selection; no playback action pushes history or marks the document
  dirty; a tab switch or frame removal stops playback.
- Playback respects layer visibility and excludes the Reference Layer
  (the `composite_at` contract — verified at this seam).

### Key Decisions

- **`advancePlayhead` is a Swift port, not a core promotion**: the function is
  simple, stable since PRD 199, and the FFI overhead would be disproportionate
  (Core Placement rule of thumb — the same reasoning family as 287's
  binding-owned duration range).
- **Start resolves edit state at the `TabState` boundary**, not inside the
  controller like the web: the Apple Floating-Selection commit is failable, so
  the guard chain lives where a failed commit can veto the start (the
  `setActiveFrame` precedent). `startPlayback` is also stroke-guarded
  (`!isDrawing`) — the web has no such guard, but every Apple frame-axis
  command shares the mid-stroke seal.
- **`PlayheadAdvance.stopped` keeps the web's field name** over the
  boolean-question naming rule — 1:1 port correspondence chosen deliberately.
- **macOS clock is a 60 Hz one-shot Timer**: macOS 14 has no standalone
  `CADisplayLink` constructor (only view/screen-anchored ones). Revisit note
  left in code if playback smoothness ever demands it.
- **Stop-hook parity verified against the web's full set** (`#mutate`,
  `drawStart`, `undo`, `redo`, workspace switch/close ↔ `performEdit`,
  `beginStroke`, `handleUndo`/`handleRedo`, `resolveOutgoingStroke`/`closeTab`).
  Active-frame switching and `nudgeMarquee` deliberately do **not** stop
  playback on either shell.

### Notes

- `advancePlayhead`'s termination relies on durations ≥ 1 ms, guaranteed today
  by the binding clamp (`MIN_FRAME_DURATION_MS = 1`). **When 292 persists
  durations, the hydration boundary must uphold the same clamp** or the advance
  loop's precondition breaks.
- Playback state is transient by construction — nothing here for 292 to
  persist (`isPlaying`/`isLooping`/playhead all reset per session).
- Transport UI (289) and onion skin (290) build directly on this slice; the
  macOS timer fallback wants a hands-on smoothness check alongside 289.
