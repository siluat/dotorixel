## What to build

The Onion Skin's state and projection layer (web PRD 217's seams, ported
to Swift) — everything except pixels on screen, which 291 renders:

- **Pure neighbor selection** — the only new algorithmic seam: given the
  frame ids in axis order, the active frame id, and a range config
  (previous/next counts), return ghost descriptors (frame id,
  previous/next kind, distance) in axis order, clamped at the axis ends,
  never wrapping. The config flows as data with the fixed v1 default
  (previous 1, next 1) so a future range control adds only UI.
- **Per-tab toggle state** (in-memory for this slice; persistence rides
  292 with the other animation state).
- **Ghost projection on the tab state**: descriptor plus the neighbor
  frame's `composite_at` buffer per ghost, computed through the existing
  render-invalidation path so ghosts reflect edits, undo/redo, and frame
  switches immediately. The projection is **empty** while the toggle is
  off, while Playback runs, or on a side with no neighbor. Computing it
  never mutates the document, never moves the Active Frame, and never
  pushes history.

## Acceptance criteria

- Neighbor-selection tests cover: middle-of-axis (both sides), first
  frame (next only), last frame (previous only), single frame (empty),
  and a larger config clamping at both ends without wrapping.
- Projection tests through the real bindings prove: buffers match the
  neighbors' committed composites (layer visibility/opacity applied,
  Reference Layer excluded); an edit or undo on a neighbor refreshes its
  ghost buffer; the projection empties while playing and returns when
  stopped; toggling and projecting push no history and mark nothing
  dirty.
