## What to build

Add the spritesheet format to the 294 export surface:

- **Spritesheet PNG**: every frame's composite as one horizontal strip
  (the 293 encoder), exported through the platform file-export flow with
  a filename that distinguishes it from the single-frame PNG (web naming
  convention as reference).
- Works for a single-frame document (a one-tile sheet) — no artificial
  frame-count gate, matching the web.
- The `SheetTooLarge` error (absurd frame counts) surfaces through the
  export-error presentation with the core's actionable message.

## Acceptance criteria

- Exporting a multi-frame document yields a PNG of canvas width × frame
  count by canvas height whose tiles match each frame's composite in
  axis order.
- A single-frame document exports a one-tile sheet identical to its
  frame composite.
- The active frame and document state are untouched by an export.
- New labels in the String Catalog (en/ko/ja).
